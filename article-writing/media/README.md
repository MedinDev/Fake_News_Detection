# Media

This directory consolidates all visual assets for the project.

## Subdirectories
- **ieee-figures/**: Figures specifically formatted for the IEEE paper.
- **supplementary-figures/**: Additional figures for supplementary materials.
- **academic-paper/**: General academic paper figures.
- **general/**: Other generated visualizations.

## Usage
Store all images and figures here. Reference them in your drafts using relative paths.
